# 词序 · Wordflow (iPhone / iPad)

这是可直接部署到 GitHub Pages 的静态网页版。无需安装 Node.js 或编译。

## 发布

1. 打开 https://github.com/new ，创建 **Public** 仓库，名称建议 `wordflow`。
2. 解压本 ZIP，将解压目录中的 `index.html`, `sw.js`, `manifest.webmanifest`, 图标文件以及 `.nojekyll` 上传到仓库根目录（不是上传 ZIP 本身）。GitHub 页面中的 `Add file` → `Upload files`。
3. 进入仓库的 `Settings` → `Pages`。
4. `Build and deployment` → `Source: Deploy from a branch` → `Branch: main` → `/(root)` → `Save`。
5. 等待部署完成，访问 `https://你的用户名.github.io/仓库名/`。
6. 在 iPhone/iPad Safari 中打开网址，`分享` → `添加到主屏幕`。

## 数据

学习记录仅保存在各设备自己的浏览器本地存储。更换域名/网址不会迁移数据。迁移前请在旧网页设置中导出 JSON 备份，再在新网页中恢复。

仓库是公开的，切勿将私人学习记录 JSON 上传到仓库。
